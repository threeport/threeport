# Oracle Cloud Infrastructure (OCI)

This section provides documentation for using Threeport with Oracle Cloud Infrastructure (OCI). OCI is Oracle's cloud platform that provides a comprehensive set of infrastructure services including compute, storage, networking, and database services.

## Key OCI Concepts

- **Tenancy**: The root compartment that contains all of your OCI resources
- **Compartments**: Logical containers for organizing and isolating your cloud resources
- **OCI Container Engine for Kubernetes (OKE)**: Oracle's managed Kubernetes service
- **Virtual Cloud Network (VCN)**: A customizable private network in OCI
- **Identity and Access Management (IAM)**: Service for controlling access to OCI resources
